# HTTP-клиент LLM: Ollama и OpenAI-совместимый API

## Назначение

Модуль реализует HTTP-клиент для двух типов LLM-серверов:

- **Ollama** — запросы к `/api/chat` и `/api/tags`;
- **OpenAI-совместимый API** — запросы к `/chat/completions` и `/models` при базовом URL, оканчивающемся на `/v1` или содержащем `/v1/`.

Режим работы определяется автоматически по `base_url`. Публичный API предназначен для отправки промптов и проверки доступности моделей. При любой ошибке клиент выбрасывает `LLMError`.

## Режимы работы

### OpenAI-совместимый режим

Включается, если URL оканчивается на `/v1` или содержит `/v1/`.

Используются endpoints:

- `POST {base}/chat/completions`
- `GET {base}/models`

Если `api_key` не пустой, передаётся заголовок:

- `Authorization: Bearer <api_key>`

В этом режиме `num_ctx` игнорируется — размер контекста определяет сервер.

### Ollama-режим

Используется во всех остальных случаях.

Endpoints:

- `POST {base}/api/chat`
- `GET {base}/api/tags`

Авторизация не используется. В запрос чата передаётся `options.num_ctx`. Если приблизительный размер промпта `len(prompt) // 4` превышает `num_ctx`, пишется предупреждение в лог, но запрос не блокируется.

## Публичный API

### `LLMError`

Исключение LLM-клиента.

Аргументы:

- `message` — текст ошибки;
- `status` — HTTP-код, если известен;
- `body` — тело ответа, если известно.

Атрибуты экземпляра: `message`, `status`, `body`.

### `chat(base_url, model, prompt, num_ctx, timeout, api_key="dummy") -> str`

Отправляет промпт в LLM и возвращает `content.strip()`.

Аргументы:

- `base_url` — базовый URL сервера;
- `model` — имя модели;
- `prompt` — пользовательский промпт;
- `num_ctx` — размер контекста для Ollama; в OpenAI-режиме игнорируется;
- `timeout` — таймаут HTTP-запроса в секундах;
- `api_key` — Bearer-токен для OpenAI-режима, по умолчанию `"dummy"`.

Поведение:

- выбирает Ollama или OpenAI-режим по `base_url`;
- при HTTP-статусе не `200`, не-JSON ответе, отсутствии `content` или пустом `content` выбрасывает `LLMError`;
- возвращает только непустой `content.strip()`.

### `check_model(base_url, model, timeout=10, api_key="dummy") -> list[str]`

Проверяет доступность LLM и возвращает список имён моделей.

Аргументы:

- `base_url` — базовый URL сервера;
- `model` — имя проверяемой модели; внутри функции не используется, наличие модели проверяет вызывающая сторона;
- `timeout` — таймаут HTTP-запроса, по умолчанию 10 секунд;
- `api_key` — Bearer-токен для OpenAI-режима.

Возвращает:

- для Ollama — имена из `models[].name`;
- для OpenAI-совместимого API — идентификаторы из `data[].id`.

Особенности:

- пустой список `[]` возможен только в OpenAI-режиме при HTTP 404 на `/v1/models`; в этом случае пишется предупреждение, а проверка имени модели пропускается;
- у Ollama пустой `/api/tags` считается ошибкой `LLMError`;
- если сервер недоступен, выбрасывается `LLMError`.

## Внутренние функции

- `_is_openai_mode(base_url)` — определяет OpenAI-совместимый режим по URL.
- `_ollama_chat_url(base_url)`, `_ollama_tags_url(base_url)` — формируют URL для Ollama.
- `_openai_chat_url(base_url)`, `_openai_models_url(base_url)` — формируют URL для OpenAI-совместимого API.
- `_auth_headers(api_key)` — формирует заголовок `Authorization`, если ключ не пустой.
- `_chat_ollama(...)`, `_check_ollama(...)` — реализация Ollama-режима.
- `_chat_openai(...)`, `_check_openai(...)` — реализация OpenAI-совместимого режима.

## Обработка ошибок и ограничения

- HTTP-статус не `200` приводит к `LLMError` с сохранением `status` и тела ответа.
- Тело ответа в ошибках обрезается до 1000 символов.
- Таймауты `requests.Timeout` и прочие `requests.RequestException` преобразуются в `LLMError`.
- Не-JSON ответ приводит к `LLMError`.
- В OpenAI-режиме проверяется наличие `choices[0].message.content`; в Ollama-режиме — `message.content`.
- Пустой или нестроковый `content` считается ошибкой.
- OpenAI-совместимые прокси могут не реализовывать `/v1/models`; ответ 404 не фатален и приводит к пустому списку моделей.
- Для Ollama пустой список моделей — ошибка с подсказкой загрузить модель через `ollama pull <name>`.
- Версия файла: `261028.12`.

## Зависимости

Импорты модуля:

- `from __future__ import annotations` — стандартная библиотека Python;
- `logging` — стандартная библиотека Python;
- `requests` — внешняя библиотека для HTTP-запросов.

Модуль не импортирует другие модули проекта. Он сам является зависимостью для вызывающего кода.

## Использование в проекте

Публичные функции `chat()` и `check_model()` предназначены для импорта другими модулями проекта.

Согласно docstring, вызывающая сторона, например `cli.py`:

- использует `check_model()` для проверки доступности LLM и получения списка моделей;
- самостоятельно проверяет наличие нужной модели в возвращённом списке и показывает список пользователю;
- использует `chat()` для отправки промпта в выбранную модель.

Точные обратные зависимости по данному файлу не видны, так как в нём нет импортов из других модулей проекта.
